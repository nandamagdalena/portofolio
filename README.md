# Portfolio — Nanda Magdalena Griselda

Website portofolio satu halaman menggunakan HTML, Tailwind CSS melalui CDN, dan JavaScript sederhana.

## Menjalankan
1. Ekstrak ZIP.
2. Buka folder `nanda-portfolio`.
3. Buka `index.html` di browser, atau jalankan Live Server dari VS Code.

Tailwind dimuat melalui CDN, jadi koneksi internet diperlukan untuk styling Tailwind dan Google Fonts.

## Kustomisasi
- Ubah konten di `index.html`.
- Ganti warna pada konfigurasi Tailwind di bagian `<head>`.
- Gambar dokumentasi ada di folder `assets/`.
- CV dan portofolio PDF juga disertakan di folder `assets/`.

Catatan: Tautan publik untuk website sekolah SMKN 4 Bojonegoro dan Laporku! tidak tercantum di dokumen sumber, sehingga belum ditambahkan.
